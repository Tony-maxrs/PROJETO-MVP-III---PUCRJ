# MVP III - Machine Learning & Analytics

Projeto desenvolvido para o MVP III da disciplina de Machine Learning & Analytics da PUC-Rio.

## Tema
Previsão de churn de clientes com o dataset Telco Customer Churn.

## Estrutura do repositório
- `Projeto_03_MVP_ML_Analytics_2026.ipynb`: notebook principal do projeto
- `datasets/WA_Fn-UseC_-Telco-Customer-Churn.csv`: base de dados utilizada

## Objetivo
Desenvolver e avaliar modelos de Machine Learning para prever o cancelamento de clientes (churn), comparando baseline, Regressão Logística e Random Forest.
